TIPS FOR PRACTICE
================================================================================

1. Start with Easy problems in each category to build fundamentals.
2. Move to Medium once you're comfortable with the pattern.
3. Attempt Hard problems only after mastering Medium ones.
4. Revisit problems after a few days to test retention.
5. Time yourself: Easy ~15 min, Medium ~25 min, Hard ~40 min.
6. If stuck for more than 10 minutes, read the approach (not code),
   then try implementing it yourself.
7. Focus on these patterns:
   - Hash maps for O(1) lookups
   - Two pointers for sorted arrays
   - Sliding window for subarrays/substrings
   - BFS/DFS for trees and graphs
   - DP for optimization problems with overlapping subproblems
